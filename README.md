# Directory & File Reference

## Key Files
- `annotations/braker_clean.gtf`: Cleaned BRAKER2 gene predictions with simplified transcript/gene IDs.
- `genomes/`: Reference assembly sequence (.fna) and index (.fai) files.
- `alignments/`: Sorted BAM alignments and index (.bai) files.

## Subdirectories
- `alignments/`: Read mapping files.
- `annotations/`: Final and intermediate GFF/GTF annotations.
- `braker/`: Raw BRAKER2 output and run artifacts.
- `databases/`: Reference protein sets and DIAMOND databases.
- `genomes/`: Assembly FASTA files.
- `reads/`: Raw and cleaned FASTQ read files.
- `scripts/`: Custom data processing and cleanup scripts.
